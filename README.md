# sanay.space, night edition

A from-scratch rebuild of the portfolio, meant to replace the old site. Main page plus the seven case studies. Not wired to git or any deploy yet; it lives only in this folder.

## Run it

```bash
npx serve -l 5174 .
```

Then open http://localhost:5174. To view it on a phone on the same wifi, use the machine's LAN address instead of localhost.

## What is in here

- `index.html`: the main page. Product design notes, experience and hackathon stories, education detail and skills all live in expandable rows, so nothing from the old page was dropped.
- `case-studies/`: one page per piece plus a hub, generated by `tools/build-case-studies.py` from `case-studies/src/*.md` (the same sources as the old repo; the vault stays canonical). Run `python tools/build-case-studies.py` after editing a source; it also refreshes the list on the main page between the `case-studies:list` markers.
- `index.html` copy: Copy is lifted from the live site, the vault Profile, the LinkedIn About draft and the 25th hour lore deck, so every fact already has a public home.
- `assets/css/case-study.css` and `assets/js/case-study.js`: the reading layout (drop cap, numbered sections, progress bar, prev and next) on top of the main tokens.
- `assets/css/main.css`: the design system. Deep cool charcoal-green ground, off-white ink, sage accent, silver hairlines. Cormorant Garamond for display, Newsreader for reading, IBM Plex Mono for labels.
- `assets/js/terrain.js`: the Three.js hero. One plane displaced by simplex noise in a vertex shader; the fragment shader draws the contour lines. Pointer, touch and (on Android) gyro tilt the camera. It pauses when the hero leaves the viewport.
- `assets/js/main.js`: loader, smooth scroll (Lenis), word reveals, the manifesto that lights up as you read, the horizontal rail (pinned to the scroll on wide windows, mouse-drag or wheel on narrower ones, swipe on phones), parallax, the lore shuffle, the London clock, the light and dark toggle (remembered in the browser), the custom cursor on pointer devices, and the lazy video.
- Light mode: the toggle in the nav (and the menu) flips a `data-theme` attribute; every colour is a token, and the terrain shader re-tints itself.
- `assets/img/`: your photos from the old repo plus three Unsplash frames (Omoide Yokocho alley, a starry ridge, a lantern alley), all exported as WebP at two sizes.
- `assets/ocean-720.mp4` and `ocean-360.mp4`: a Pexels aerial ocean loop, trimmed to 20 seconds and desaturated. Phones and slow connections get the small one.

## External dependencies (CDN, no build step)

- three 0.160.0 (jsDelivr)
- gsap 3.13 with ScrollTrigger (jsDelivr)
- lenis 1.3.4 (jsDelivr)
- Google Fonts: Cormorant Garamond, Newsreader, IBM Plex Mono, and a five-glyph subset of Noto Serif JP

## Replacing the old site

Copy everything in this folder over the `portfolio` repo (keep its `.git`), delete the old `Pictures/`, `assets/hero.jpg`, `assets/case-study.*` and the old `tools/`, then commit and push. GitHub Pages and Vercel both build from `main`, so one push updates both.
